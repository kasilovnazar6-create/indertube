# InderTube

Видеохостинг на Python: обычные видео и вертикальные **Shorts**, каналы,
подписки, комментарии, плейлисты и творческая студия.

**Стек:** Flask 3 · SQLite (stdlib `sqlite3`) · Jinja2 · ванильный JS/CSS · Pillow.
Без внешних сервисов и CDN — всё работает локально.

---

## Быстрый старт

```bash
python -m pip install -r requirements.txt
python app.py
```

Откройте **http://127.0.0.1:5000** и создайте первый канал — база пустая,
демо-аккаунтов нет. SQLite-база `data/indertube.db` создастся автоматически.

На Windows можно запустить `run.bat`.

### Проверка

```bash
python smoke_test.py
```

41 сценарий на изолированной временной базе: страницы, регистрация, CSRF,
загрузка видео и Shorts, вертикальные превью, лимит 60 секунд, лайки,
комментарии, подписки, плейлисты, поиск, Range-запросы и удаление.
Для тестов загрузки нужен `ffmpeg` (если его нет — эти проверки пропускаются).

## Что умеет

**Аккаунты и каналы**
- регистрация с проверкой e-mail/ника, вход/выход, смена пароля;
- страница канала: баннер, аватар, описание, статистика, вкладки «Видео», «Shorts», «О канале»;
- настройки: имя, ссылка, описание, аватар, цвет аватара и баннера.

**Видео**
- загрузка MP4/WebM/MOV до 2 ГБ с drag&drop;
- автоматическое превью из кадра видео или своя картинка;
- fallback-превью генерируется на сервере через Pillow;
- потоковая отдача с `Range` — перемотка работает;
- доступ: открытое / по ссылке / личное;
- редактирование и удаление в студии.

**Shorts**
- отдельная лента с вертикальным скроллом и автовоспроизведением;
- вертикальные превью 9:16 и лимит длительности 60 секунд;
- звук включается одной кнопкой и запоминается;
- лайки, комментарии в боковой панели, «Поделиться», подписка на канал;
- витрина Shorts на главной и вкладка на канале;
- `/watch/<id>` для Shorts автоматически ведёт в ленту.

**Взаимодействие**
- лайки и дизлайки, комментарии с ответами и лайками;
- подписки и лента свежих видео;
- история просмотров, «Понравившиеся», «Смотреть позже», плейлисты;
- счётчик просмотров — один просмотр на видео за сессию.

**Поиск и лента**
- поиск по названиям, описаниям и каналам + сортировка;
- живые подсказки, категории, «В тренде», похожие видео.

**Интерфейс**
- переключатель светлой/тёмной темы прямо в шапке (и в меню аккаунта);
- тёмная и светлая темы запоминаются в `localStorage`;
- сворачиваемый сайдбар, мобильная вёрстка, русская локализация чисел и склонений.

**Безопасность**
- пароли — `werkzeug.security` (scrypt), подписанные сессии;
- CSRF-токен для всех POST/DELETE;
- проверка владельца, экранирование Jinja, whitelist расширений.

## Полезные детали

- **Просмотры** инкрементируются через `POST /api/videos/<id>/view` один раз
  за сессию; для авторизованных пишется история.
- **Раздача видео** идёт через `send_from_directory(..., conditional=True)` —
  Flask обрабатывает `Range` и `ETag`.
- **Превью** для загруженных роликов снимается в браузере на 10% длительности:
  canvas 1280×720 для видео и 720×1280 для Shorts.
- **Лимит Shorts** проверяется на сервере по длительности из формы, поэтому
  обойти его через интерфейс нельзя.
- **Счётчики** лайков/комментариев считаются подзапросами в SQL.

## Ограничения

- Встроенный сервер Flask — для локального запуска; для продакшена используйте
  `waitress`/`gunicorn` и reverse proxy.
- Нет транскодинга: загружайте MP4 (H.264) или WebM, иначе браузер не проиграет.
- SQLite и локальный диск рассчитаны на небольшой проект.
